# 기술 방향 비교와 권장 구성

| 기술 | 개발 속도 | 대규모 전투 | 브라우저 안정성 | 비주얼 자유도 | 테스트 용이성 |
|---|---:|---:|---:|---:|---:|
| Phaser 3 | 5 | 4 | 5 | 4 | 5 |
| PixiJS | 3 | 5 | 5 | 5 | 4 |
| Godot Web | 4 | 3 | 3 | 4 | 2 |
| Three.js | 2 | 4 | 3 | 5 | 3 |

## 초기 권장 구성

Phaser 3 + TypeScript + 사용자 정의 경량 전투 시뮬레이션 + Cloudflare Pages를 사용한다.

## 현재 기술 선택 단계

사용자가 장난감 전쟁 디오라마를 선택함에 따라 Phaser 2D, Three.js 2.5D와 Three.js 실시간 3D를 동일한 전투 코어로 비교한다. 초기 권장안은 비교 전의 안전 기준선이며 최종 선택이 아니다. 성능·가독성·미니어처 촉감과 에셋 제작 시간을 측정한 뒤 하나를 확정한다. 상세 기준은 [테이블탑 3렌더러 비교 프로토타입 설계](../../superpowers/specs/2026-08-12-tabletop-renderer-comparison-design.md)를 따른다.

## 목표 성능 예산

- 적군 평상시 150~250명, 최대 약 300명
- 아군 16~24명
- 투사체 최대 약 200개
- 동시 효과 약 100개
- 데스크톱 60FPS 목표, 저사양 환경 30FPS 하한
- 초기 다운로드 가능하면 25MB 이하
- 첫 플레이 시작 5초 이내

## 분대 이동

1. 지휘관만 목표 위치로 이동한다.
2. 병사는 지휘관 주변의 진형 슬롯을 배정받는다.
3. 병사는 슬롯을 향해 이동하며 가까운 아군끼리만 밀어낸다.
4. 장애물 근처에서만 제한적인 회피를 수행한다.

## 적 AI

- 군중형: 가장 가까운 분대 중심을 추적
- 사냥꾼형: 지휘관 또는 구조 중인 병사를 공격
- 지휘관형: 주변 적에게 사기와 속도 보너스 제공

## 저장과 서비스

- MVP는 로그인과 데이터베이스 없이 버전형 `localStorage`만 사용한다.
- 공개 URL을 열면 설치나 승인 없이 즉시 시작한다.
- 계정, 서버 저장과 Hive 기능은 핵심 루프 검증 이후 확장한다.

## 검증

- Vitest: 피로, 사기, 구조, 업그레이드와 웨이브 계산
- Playwright: 시작, 조작, 레벨업, 분대 전환과 게임 종료
- 성능 시나리오: 적 300명과 투사체 200개
- 배포 스모크: 깨끗한 브라우저의 에셋·콘솔·입력 확인
