# 기술 D — Three.js 2.5D 디오라마

장난감 전쟁 아트의 입체감과 발표 영상을 우선하는 안이다.

## 구성

- TypeScript, Three.js
- 직교 카메라와 저폴리곤 인스턴싱
- 캐릭터는 저폴리곤 모델 또는 빌보드 스프라이트
- 최소한의 그림자와 후처리

## 장단점

- 미니어처, 재질, 깊이감과 카메라 연출이 뛰어나다.
- 트레일러와 발표 장면의 시각적 효과가 크다.
- 모델, 리깅, 텍스처 제작량이 늘어나고 저사양 브라우저 검증 부담이 크다.
- 그림자와 원근이 탑다운 전투 가독성을 떨어뜨릴 수 있다.

## 사용 조건

- 장난감 디오라마 아트를 최종 선택하고 3D 에셋 제작 역량과 시간이 확보됐을 때만 선택한다.
- 모든 반복 캐릭터는 인스턴싱하고 동적 광원과 후처리를 제한한다.
