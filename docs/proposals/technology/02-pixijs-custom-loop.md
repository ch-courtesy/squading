# 기술 B — PixiJS + 자체 게임 루프

성능과 화면 연출을 우선하는 안이다.

## 구성

- Vite, TypeScript, PixiJS
- 고정 시간 간격 시뮬레이션과 렌더 보간
- 배열 기반 엔티티 데이터
- Vitest, Playwright, Cloudflare Pages

PixiJS는 렌더링에 집중시키고 입력, 오디오, 상태 전환과 전투 규칙을 직접 구현한다. 병사의 위치, 체력, 피로, 분대와 상태는 객체 묶음보다 구조화된 배열로 관리할 수 있다.

## 장단점

- 많은 스프라이트의 배치 렌더링과 파티클 제어에 유리하다.
- 먹 번짐, 홀로그램, 유리 파편 같은 효과를 세밀하게 만들 수 있다.
- 게임 프레임워크 기능을 직접 구성해야 하며 자체 엔진 제작으로 범위가 커질 위험이 있다.

## 사용 조건

- 성능 프로파일에서 Phaser 목표를 충족하지 못했거나 특수 렌더링이 제품 정체성의 핵심일 때 선택한다.
- 입력, 씬과 오디오 계층은 최소 범위만 구현한다.

적합 아트: 네온, 먹빛, 스테인드글라스  
개발 위험: 중간 · 추천 순위: 2위
