# 기술 C — Godot 4 Web Export

비주얼 에디터와 게임 제작 도구를 우선하는 안이다.

## 구성

- Godot 4, GDScript
- Web Export와 정적 호스팅
- 내장 씬, 파티클, 애니메이션과 오디오 도구

## 장단점

- 화면 배치와 애니메이션 조정이 빠르고 아티스트가 직접 편집하기 좋다.
- 데스크톱 빌드로 확장하기 쉽다.
- 초기 다운로드, 모바일 브라우저와 일부 WebGL 환경의 검증 부담이 크다.
- 자동 브라우저 테스트와 게임 규칙 단위 테스트가 TypeScript 구성보다 불편하다.

## 사용 원칙

- 병사마다 복잡한 노드를 만들지 않고 배치 렌더링을 사용한다.
- 웹 스레드나 고급 렌더링 기능에 의존하지 않는다.
- Chrome과 Safari의 깨끗한 세션에서 시작 시간과 입력을 반복 검증한다.

적합 아트: 장난감 디오라마, 스테인드글라스  
개발 위험: 중상 · 추천 순위: 3위
