# 기술 A — Phaser 3 + TypeScript

대회 제출용 권장안이다.

## 구성

- Vite, TypeScript, Phaser 3
- Vitest 단위 테스트, Playwright 브라우저 테스트
- Cloudflare Pages 정적 배포
- 버전이 포함된 `localStorage` 저장

Phaser는 렌더링, 입력, 카메라, 오디오와 씬 전환을 담당한다. 전투 규칙은 Phaser 객체와 분리한 경량 시뮬레이션 모듈로 구현한다.

## 구현 원칙

- 적 하나마다 Phaser 물리 객체를 만들지 않는다.
- 공간 격자와 원형 거리 판정으로 공격 대상을 찾는다.
- 적, 투사체와 효과는 오브젝트 풀을 사용한다.
- 피로, 사기, 구조와 웨이브 계산은 렌더러 없이 테스트 가능하게 한다.
- 완전한 ECS나 범용 엔진 추상화는 MVP에서 만들지 않는다.

## 장단점

- 브라우저 게임 기능이 갖춰져 있어 개발과 배포가 빠르다.
- Canvas/WebGL 대응과 Playwright 검증이 쉽다.
- 일반적인 Phaser 객체 모델만 사용하면 대규모 전투 성능이 떨어지므로 시뮬레이션 분리가 필수다.
