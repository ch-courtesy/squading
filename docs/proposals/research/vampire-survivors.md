# 《뱀파이어 서바이벌》 리서치

## 핵심 발견

- 직접 입력을 이동에 집중시키고 공격을 자동화해 위치 선정과 위험 관리가 핵심 판단이 된다.
- 경험치 수집과 제한된 레벨업 선택이 약한 생존자를 화면 장악형 빌드로 변화시킨다.
- 시간에 따라 적의 수·종류·압박 방향을 바꿔 별도의 복잡한 서사 없이 긴장 곡선을 만든다.
- 짧은 실패와 재시도, 무기 조합과 진화, 영구 해금이 반복 플레이를 유도한다.
- 원작의 15~30분 런보다 대회용 브라우저 MVP에는 8~12분 런이 적합하다.

## 가져올 설계 원리

- 이동 중심 조작과 자동 공격
- 다수의 적과 명확한 웨이브
- 전투 중 즉시 체감되는 성장
- 한 번에 3개 안팎의 읽기 쉬운 선택지
- 짧고 반복 가능한 런과 명확한 종료 조건

## 브라우저 구현 시사점

- 적, 투사체, 피격 효과는 오브젝트 풀을 사용한다.
- 전역 물리 충돌 대신 공간 격자와 원형 거리 판정을 사용한다.
- 일반 전투 목표는 적 150~250명, 최대 부하 목표는 약 300명으로 둔다.
- 레벨업 선택 화면은 전투를 멈추되 한 런에서 3~4회 정도로 제한한다.

## 차별화 기회

- 혼자 살아남는 영웅 대신 두 개의 살아 있는 AI 분대를 지휘한다.
- 화력 성장뿐 아니라 진형, 교대, 피로, 구조, 사기를 성장 축으로 사용한다.
- 화면 삭제형 빌드보다 병사 생존과 적 지휘관 제거를 중요한 목표로 둔다.

## IP 안전선

- 고유 캐릭터·무기 이름·몬스터·그래픽·음원·상자 연출·슬롯 UI를 사용하지 않는다.
- 자동 공격, 경험치 수집, 웨이브, 선택형 성장처럼 추상적인 규칙만 참고한다.
