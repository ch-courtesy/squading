# 《퍼스트 퀸 4》 리서치

## 핵심 발견

- 많은 병사가 각자의 판단으로 실시간 전투를 벌이고 플레이어는 지휘관을 통해 간접 통제한다.
- 두 부대가 동시에 참여하고 실시간으로 교대할 수 있어 전투와 회복의 리듬이 생긴다.
- 피로가 장기 전투의 지속 능력에 영향을 준다.
- 병사는 단순한 탄환이 아니라 이름과 생존 여부가 있는 전력이다.
- 적 지휘관 격파, 항복·영입, 구조 같은 결과가 전투 이후의 서사를 만든다.

## 가져올 설계 원리

- 두 개의 AI 분대와 현재 지휘 분대 전환
- 공격·집결·돌격·후퇴 정도의 소수 명령
- 전투 분대와 회복 분대를 번갈아 쓰는 피로 관리
- 쓰러짐 → 구조 가능 시간 → 사망의 단계
- 적 지휘관 제거에 따른 사기 붕괴와 패주
- 생존자의 이름, 부상, 전공을 남기는 결과 화면

## 현대화 원칙

- 아군은 총 16~24명으로 제한해 개별 병사의 가치를 보이게 한다.
- 모든 병사에게 완전한 경로 탐색을 적용하지 않고 지휘관 경로, 진형 슬롯, 근거리 회피를 사용한다.
- 복잡한 메뉴식 지휘 대신 이동, 분대 전환, 집결/후퇴 중심으로 조작을 단순화한다.
- 장기 캠페인보다 8~12분 전투 또는 3전투 약 25분 캠페인으로 압축한다.

## 결합 시 주의점

- 지나친 광역 화력은 아군 개성과 진형을 가리므로 제한한다.
- 잦은 레벨업은 지휘 흐름을 끊으므로 한 전투에 3~4회만 제공한다.
- 피로가 단순 페널티가 되지 않도록 분대 교대의 보상으로 설계한다.

## IP 안전선

- 원작의 인명, 지명, 세계관, 스토리, 캐릭터 디자인, 맵, UI, 음원과 전직을 사용하지 않는다.
- 두 부대, 간접 지휘, 피로, 구조, 사기처럼 추상적인 시스템만 참고한다.
