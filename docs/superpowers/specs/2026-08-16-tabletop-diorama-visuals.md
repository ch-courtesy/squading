# 테이블탑 디오라마 비주얼 명세

승인된 아트 방향 `docs/proposals/art/03-tabletop-war-diorama.md`와 그 콘셉트 이미지를 게임 화면에 구현한다. 게임플레이 규칙, 권위 상태, 결정론과 8-seed 밴드는 이 작업에서 바뀌지 않는다.

## 고정 제약

- 외부 런타임 의존성과 외부 에셋을 추가하지 않는다. 모든 형상과 텍스처는 Three.js primitive와 코드 생성 canvas로 만든다.
- `core/gameplay/`는 수정하지 않는다. 렌더러는 `RenderSnapshot`만 읽는다. 시각용 난수는 권위 밖 cosmetic seed를 쓰고 `GameState` digest에 영향을 주지 않는다.
- 렌더러 비교 lab(`?lab=renderers`)의 기존 billboard 표현과 테스트 의미를 바꾸지 않는다. 디오라마 표현은 gameplay snapshot에서만 켜진다(활성 분대 마커와 같은 신호를 사용한다).
- 성능: 1440x900, 유닛 60기 기준으로 프레임 예산을 넘기지 않는다. 유닛당 draw call은 미니어처 본체 1 + 베이스 링 1 + 접지 그림자 1을 넘지 않는다.

## 콘셉트 이미지에서 가져올 요소

1. **보드**: 모래빛 상판에 격자 이음새와 마모, 가장자리 프레임. 코드 생성 canvas 텍스처.
2. **미니어처**: 카드가 아니라 조각된 미니어처. 원형 베이스 + 몸통 + 머리 + 어깨 + 무기를 하나의 병합 지오메트리로 만들고 병과별 변형을 둔다.
3. **진영 색**: 청록 아군, 주홍 아군, 자주색 적, 정예는 더 크고 받침대 위에 선다.
4. **베이스 링**: 유닛마다 색 링. 활성 분대는 밝게 맥동하고, downed는 금색, 정예는 자주색.
5. **지형 소품**: 나무 상자 바리케이드, 침엽수, 진영 깃발. 플레이 영역 밖 가장자리에 cosmetic seed로 결정론적으로 배치하며 게임 판정에 관여하지 않는다.
6. **구조 연출**: 쓰러진 미니어처는 옆으로 넘어지고, 구조 중에는 금색 기둥 빛과 회전 링이 올라온다.
7. **위험 표시**: 정예 예고는 붉은 문양 링이 맥동한다. 반지름은 권위 스냅샷의 값을 그대로 쓴다.

## 액션 피드백

- 공격: 공격 tick에 미니어처가 대상 방향으로 짧게 전진했다 복귀하고, 총구에 솜뭉치 퍼프가 한 프레임 뜬다.
- 피격: 대상 색이 순간 밝아지고 살짝 뒤로 밀린다.
- 사망: 미니어처가 넘어지며 종이 조각이 흩어진다.
- 정예 범위 공격: 착탄 순간 화면이 짧게 흔들린다.
- 모든 연출은 표시 전용이며 권위 좌표·판정을 바꾸지 않는다. 연출 상태는 렌더러 내부에만 존재한다.

## 검증

- 기존 유닛·E2E 테스트가 모두 통과한다.
- 프레이밍 테스트(모든 유닛이 화면 안)와 lab 회귀 테스트가 통과한다.
- 디오라마 표현이 gameplay route에서만 켜지고 lab route에서는 기존 billboard가 유지됨을 테스트로 고정한다.
- 실제 브라우저 스크린샷으로 콘셉트 대비 결과를 기록한다.
