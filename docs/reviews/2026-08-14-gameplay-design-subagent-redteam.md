# 서브에이전트 적대적 리뷰 — 핵심 게임 루프 설계

- 판정: **REJECT — 구현 승인 불가**
- 파일 수정 없이 독립 검토

## Critical 요약

1. 보스 우선 공격 수단 없이 nearest-only 공격으로 15초 보스 처치를 요구해 승리가 플레이어 통제 밖이다.
2. Space hold, pointer release, pause와 레벨업 입력 계약이 없다.
3. 최종 render snapshot hash는 cooldown·XP·카드·PRNG·wave cursor를 포함하지 않아 결정론 거짓 양성이 가능하다.
4. 주홍의 이론 DPS 우위는 약 16%인데 청록 유효 체력은 약 2배라 역할 차이가 불명확하다.
5. 다수 적 접촉 피해 상한과 공격 직전 표적 재선택이 없어 순간 전멸·overkill이 발생할 수 있다.
6. 첫 30초에 구조·교대·강화의 고유 재미가 보장되지 않는다.

## Kill list

- 실시간 3D renderer와 비교 UI
- Phaser fallback의 완전한 parity 확장
- 사기와 지휘관 오라 상세 구현
- 관통·연속 사격 등 추가 projectile 규칙
- 5개 강화 범주 전체
- 코드 생성 음향·품질 ladder 확장
- 재미 검증 전 과도한 core 모듈 분할

## 권고 30초 수직 슬라이스

- 0~8초: 첫 구조 기회
- 8~18초: 적 밀도 증가와 분대 교대
- 10~15초: 강화 3택 1회
- 18~30초: 경고 범위 공격을 가진 정예 1명
- 30초 정예 처치 시 성공, 무입력은 실패
- 포함: 위치 기반 공격, 두 비대칭 분대, 교대 cooldown, 단순 피로, 구조, 강화 1회
- 제외: 사기, 최종 보스, 성장 4회, renderer parity, 음향 polish

## 권고 인수 기준

- 고정 seed 8개에서 무입력 0/8 승리, 숙련 정책 6/8 이상 승리, 이동 전용 2/8 이하 승리
- 첫 조작 가능 ≤3초, 첫 공격 ≤5초, 구조 기회 ≤8초, 첫 강화 ≤15초
- 원거리 Space 90 tick은 구조 진행도 0
- 근거리 44 tick 미완료, 45 tick 완료
- 교대 정책의 30초 피해량이 단일 분대 연속 사용보다 최소 20% 높음
- 동일 replay의 권위 상태 checkpoint digest 전부 동일
- 실제 키·포인터·카드 입력 E2E가 정확한 결과·구조 수·선택 카드·보스 HP를 검증
